# Mountequipment

Adds 3 enchantments for mount equipment:

## Flying Mount Speed
* **Item**: Harnass
* **Effect**: 25% Speed increase per level

## Mount Speed
* **Item**: Saddle
* **Effect**: 10% speed increase per level

## Lifetranser
* **Item**: Horse Armor
* **Effect**: Heals the mount in exchange for consuming player saturation
