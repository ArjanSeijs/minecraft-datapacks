# Datapacks

An assortment of various datapacks

* [Mount Equipment](./mountequipment/README.md): Ads a few enchantments for mount gear
* [Schedulelib](./schedulelib/README.md): A library for scheduling commands and functios, keeping track if player execution contexts and function arguments
* [Sleeptweaks](./sleeptweaks/README.md) Apply affects on sleep
* [Soaplib](./soaplib/README.md): Common functionality for other datapacks
* [Spawner Upgrade](./spawner_upgrader/README.md): Utility tool to edit spawner properties
* [Tradetweaks](./tradetweaks/README.md): Tweaks to enchanted book trades of librarians.
