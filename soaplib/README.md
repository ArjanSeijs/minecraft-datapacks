# Utility function library

Contains some utility tags, predicates and functions.

## Functions WIP
See `data/soaplib/function/api`

### Stable:
* `soaplib:api/component/patch` apply modifier to items in player inventory


## Predicates

* `api/chance/<number>.json` some premade chance predicates.
* `api/villager/job/<profession>.json` villager profession predicates
* `api/villager/level/<level>.json` villager level predicates



## Tags
**Functions**:
* `soaplib:onload` equivalent to the minecraft:load tag but for packs that are dependend on soaplib
* `soaplib:ontick` equivalent to the minecraft:tick tag but for packs that are dependend on soaplib
* `soaplib:ontick1s` similiar to minecraft:tick but only execute every second
